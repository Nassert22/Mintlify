# AI Engineer Badge — برنامج التدريب

موقع توثيقي (Mintlify) يحتوي على برنامج تدريب كامل للتحضير لشارة **مهندس ذكاء اصطناعي** من الهيئة السعودية للبيانات والذكاء الاصطناعي (SDAIA) بمستوى **Expert**.

## التشغيل محليًا

```bash
npm i -g mint
mint dev
```

ثم افتح `http://localhost:3000`.

## المحتوى

- `index.mdx` — نظرة عامة على الشارة والمجالات والأوزان
- `self-assessment.mdx` — اختبار تشخيصي لتحديد نقطة البداية
- `study-plan.mdx` — خطة دراسة 12 أسبوعًا موزونة حسب أوزان المجالات
- `domains/` — صفحة لكل مجال من المجالات السبعة
- `capstone.mdx` — مشروع تطبيقي يغطي كل المجالات
- `capstone-darvin.mdx` — تطبيق البرنامج على نظام دارفن (مشروع حقيقي)
- `exam-day.mdx` — استراتيجية الاختبار
